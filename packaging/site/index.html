BenchBob

A bench server with a web dashboard, for a Raspberry Pi or any other 64-bit Debian-family Linux box. Plug things into it and use them from anywhere on the LAN, from a browser, a script or an AI agent. Source, docs and releases: github.com/cinderblock/BenchBob.

No login. Anyone who can reach BenchBob can erase and flash drives, change the boot config, reboot, and drive GPIO and USB power. Run it only on a network you trust.

Install

curl -fLO https://github.com/cinderblock/BenchBob/releases/latest/download/benchbob_$(dpkg --print-architecture).deb
sudo apt install ./benchbob_*.deb

The package adds this apt repository, so later releases arrive with sudo apt upgrade or the dashboard's Update button.

Just the apt repository

sudo curl -fsSLo /usr/share/keyrings/benchbob-archive-keyring.asc https://cinderblock.github.io/BenchBob/apt/benchbob-archive-keyring.asc
printf 'Types: deb\nURIs: https://cinderblock.github.io/BenchBob/apt\nSuites: stable\nComponents: main\nSigned-By: /usr/share/keyrings/benchbob-archive-keyring.asc\n' | sudo tee /etc/apt/sources.list.d/benchbob.sources
sudo apt update && sudo apt install benchbob
