BenchBob node: Wi-Fi config for a Pico 2 W

Makes a config.uf2 that writes only the node's config region. Nothing leaves this page.

The file holds the Wi-Fi password in plain text. Delete it once the node is set up.

Then

  1. Flash the firmware first: benchbob-node-pico2w.uf2 from the releases (skip if it's already on the board).
  2. Hold BOOTSEL and plug the Pico 2 W in. A drive called RP2350 appears.
  3. Copy config.uf2 onto it. The board restarts and joins the network.
  4. Open http://<hostname>.local/api/status. The LED is on when it's connected, blinks fast while it connects, and slowly if it has no Wi-Fi settings.

Reflashing the firmware later keeps these settings. To change them, copy a new config.uf2, or use Improv Wi-Fi over USB at improv-wifi.com.
