# CYW43439 firmware

Wi-Fi firmware, CLM and NVRAM blobs for the Pico 2 W's CYW43439, linked into the image
with `include_bytes!`. Copied unchanged from the `cyw43-firmware/` directory of
[embassy-rs/embassy](https://github.com/embassy-rs/embassy) at tag `embassy-rp-v0.10.0`
(the version `cyw43` 0.7 expects), which takes them from
[georgerobotics/cyw43-driver](https://github.com/georgerobotics/cyw43-driver/tree/main/firmware).
